# 2026-04-28 M50 Axis 1 선호도 반영 가시성 중재 권고

## 상황 요약
- **현재 상태**: M49 family (교차 세션 선호도 반영)의 모든 구현 단계(계약 정의, 신뢰도 필터, 요약 파이프라인 주입 및 웹 조사 제외)가 완료 및 검증되었습니다. PR #47, #48이 발행되어 머지를 대기 중입니다.
- **이슈**: M49를 통해 "선호도 주입"이라는 비가시적 로직이 완성되었으나, 사용자가 이를 직관적으로 확인하고 감사(audit)할 수 있는 UI 표면이 `MessageBubble` 팝오버에 국한되어 접근성이 낮습니다.
- **판정**: M50의 첫 번째 목표로 **선호도 주입 결과의 가시성(Visibility)**을 강화하여, 시스템의 현재 상태를 투명하게 노출하고 향후 피드백 루프(M50 Axis 2)를 위한 UI 기반을 마련해야 합니다.

## 분석
1. **M49 계약 이행 완료**: Axis 1에서 정의한 모든 계약(신뢰도 필터링, 요약 포함, 웹 제외 등)이 Axis 3까지 거치며 완전히 이행되었습니다. 기술적으로 "반영" 루프의 한 축이 완성되었습니다.
2. **가시성 갭(Gap)**: `AgentResponse`에는 이미 `applied_preferences`가 포함되어 있으나, 사용자는 개별 메시지의 작은 배지를 클릭해야만 내용을 볼 수 있습니다. 글로벌 `PreferencePanel`(사이드바)은 모든 활성 선호를 보여줄 뿐, "이 응답에 실제 무엇이 쓰였는지"를 상시 노출하지 못합니다.
3. **M50 Axis 1 가치**: 사이드바에 "이번 응답에 반영된 선호" 섹션을 추가함으로써, AI의 동작 근거를 상시 노출(Grounded Transparency)할 수 있습니다. 이는 "가르칠 수 있는 개인용 비서"라는 제품 목표에 부합하는 사용자 경험 개선입니다.

## 권고 사항
- **결정**: `RECOMMEND: implement M50 Axis 1 — 선호도 주입 결과 가시성`
- **사유**: 주입 로직(M49)의 완성을 사용자 가치로 연결하기 위해서는 투명한 노출이 필수적입니다. 글로벌 패널과 메시지 컨텍스트를 연결하는 가시성 강화는 다음 단계인 피드백 루프의 필수 전제 조건이기도 합니다.
- **첫 번째 슬라이스**: 글로벌 `PreferencePanel` (사이드바)에 현재 선택된 메시지 또는 마지막 응답에 반영된 선호도 목록을 별도 섹션으로 표시.
