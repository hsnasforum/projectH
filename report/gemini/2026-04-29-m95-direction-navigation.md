# 2026-04-29 M95 방향 제언: 선호 반영 가시성 및 탐색 강화 (Gemini)

## 1. 개요
M94 Axis 1-2를 통해 '신뢰도 높음' 배지가 적용된 applied preferences 팝오버가 성공적으로 구현 및 발행되었습니다. 현재 PR #71~#84가 머지 대기 중인 상태에서, M94의 성과를 확장하고 사용자 경험을 완성하기 위한 M95 방향을 제언합니다.

## 2. 조사 및 판단

### 2.1. M94 성과 및 한계
- **성과:** 모델 응답에 영향을 준 선호도의 신뢰도를 팝오버에서 직접 확인할 수 있게 되어, '메모리 주입' 과정의 투명성이 확보되었습니다.
- **한계:** 팝오버에서 개별 선호도의 존재는 알 수 있으나, 해당 선호도의 상세 내용(정의, 통계 등)을 확인하려면 사용자가 직접 `PreferencePanel`에서 해당 항목을 찾아야 하는 탐색 비용이 존재합니다.

### 2.2. M95 후보군 분석
- **후보 B3 (팝오버 → 상세 이동 링크):** 현재 활성화된 '가시성(Visibility)' family에 속하며, '영향(Impact)' 확인 지점에서 '정의(Source)' 관리 지점으로의 연결을 완성합니다. 이는 가장 즉각적인 사용자 가시성 개선입니다.
- **후보 A1 (자동 활성화 알림):** '승격 UX' family로의 전환을 의미합니다. 중요하나, 현재 진행 중인 가시성 강화의 흐름을 끊지 않고 B3를 통해 먼저 UX 완성도를 높이는 것이 효율적입니다.
- **후보 B2 (Testability):** 내부 품질 개선으로 중요도가 상대적으로 낮습니다.

## 3. 권고 (Recommendation)

**RECOMMEND: implement Option B3 — applied preferences 팝오버에서 preference 상세로 이동 링크**

### 기술/제품적 이유:
1. **UX 루프 완성:** 팝오버(응답 영향 확인)에서 상세 패널(관리/조정)로의 직접적인 이동 경로를 제공하여, 선호 메모리 기능의 '폐쇄 루프(Closed Loop)' 탐색을 지원합니다.
2. **동일 family 집중:** M94(Option B)에서 시작된 '가시성 및 투명성' 강화 축을 유지하여, 하나의 기능 단위를 밀도 있게 완성합니다.
3. **가시성 강화의 연장:** 단순히 '반영됨'을 보여주는 것을 넘어, 사용자가 해당 선호의 '근거'로 즉시 접근하게 함으로써 시스템의 Teachable 성격을 강화합니다.
