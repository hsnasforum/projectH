## 사용 skill

- `finalize-lite`: 문서 전용 라운드의 검증 범위와 `/work` closeout 필요 여부를 점검.

## 변경 이유

- M114 Axis 1에서 user-triggered `activate_preference()`가 JSON/SQLite preference record에 `is_highly_reliable = True`를 명시 저장하도록 바뀌었다.
- product docs가 기존 통계 기반 신뢰도 계산 설명만 담고 있어, 수동 활성화 선호의 즉시 주입 자격과 자동 활성화 경로의 분리를 문서화할 필요가 있었다.

## 핵심 변경

- `docs/PRODUCT_SPEC.md`에 저장된 명시 `is_highly_reliable` 값이 우선되고, 수동 `activate_preference()`가 즉시 세션 주입 자격을 부여한다는 설명을 추가했다.
- `docs/ACCEPTANCE_CRITERIA.md`에 리뷰 후보 수동 활성화 직후 같은 세션 주입 후보로 인정되어야 한다는 기준을 추가했다.
- `docs/ARCHITECTURE.md`에 JSON/SQLite `activate_preference()`가 `is_highly_reliable = True`를 저장하며 `AgentLoop._get_active_preferences()` / `is_highly_reliable_preference()` 필터와 연결된다는 구조 설명을 반영했다.
- `docs/MILESTONES.md`에 M114 Axis 1/Axis 2 완료 항목을 추가했다.
- `docs/TASK_BACKLOG.md`의 현재 next phase 요약과 구현 완료 목록에 M114 완료 사실을 추가했다.
- `_auto_activate_candidate_if_ready()`는 계속 통계 기반 자동 활성화 경로로 남는다고 명시해 코드 변경 범위를 과장하지 않았다.
