## 사용 skill

- `doc-sync`: M115 Axis 1 구현 사실을 product docs와 milestone/backlog 문서에 맞추기 위해 사용.
- `finalize-lite`: docs-only 라운드의 검증 범위와 closeout 준비 상태를 점검하기 위해 사용.
- `work-log-closeout`: `/work` closeout 형식과 필수 섹션을 맞추기 위해 사용.

## 변경 이유

- M115 Axis 1에서 `AgentLoop._get_active_preferences()`가 현재 사용자 입력 기반 컨텍스트 관련성 필터와 `preference_injected` task log 이벤트를 추가했지만 product docs에는 아직 반영되지 않았다.
- 이번 handoff는 코드/테스트가 이미 검증된 상태에서 문서만 동기화하는 Axis 2 범위다.

## 핵심 변경

- `PRODUCT_SPEC`에 선호 주입 관련성 필터, `fallback_all` 유지, `preference_injected` task log 이벤트를 반영했다.
- `ACCEPTANCE_CRITERIA`에 `description` / `corrected_text`와 `user_input` 단어 중첩, fallback, event detail 기준을 추가했다.
- `ARCHITECTURE`에 `_get_active_preferences(user_input, session_id)` 시그니처, 단순 키워드 중첩 방식, 비차단 task log 기록을 문서화했다.
- `MILESTONES`에 M115 Axis 1/2 완료 섹션과 Next Priority 완료 표기를 추가했다.
- `TASK_BACKLOG`의 current product identity와 implemented 목록에 M115 완료 항목을 추가했다.
- 코드와 테스트 파일은 수정하지 않았다.
