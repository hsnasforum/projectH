## 사용 skill

## 변경 이유

M122 Axis 3 `UNRESOLVED` display/hint 전파 구현은 완료됐지만 `docs/MILESTONES.md`와
`docs/TASK_BACKLOG.md`에 마지막 완료 사실이 반영되지 않았다. 이번 라운드는 핸드오프가 지정한
두 문서만 동기화해 M122 entity-card 웹 조사 품질 개선 3축의 남은 문서 gap을 닫는 범위로
수행했다.

## 핵심 변경

- `docs/MILESTONES.md`의 M122 섹션에 `Axis 3: UNRESOLVED display/hint 전파 - DONE`
  항목을 추가했다.
- `_claim_coverage_status_label()`이 `CoverageStatus.UNRESOLVED`를 `미해결`로 표시하고,
  `_claim_coverage_status_rank()`이 UNRESOLVED를 rank 0으로 명시한다는 완료 사실을 기록했다.
- `_build_claim_coverage_progress_summary()`가 unresolved slot 집합에 UNRESOLVED를 포함하고,
  `_annotate_claim_coverage_progress()`는 rank/label 호출자를 통해 UNRESOLVED를 자동 처리한다는
  문서 설명을 추가했다.
- `docs/MILESTONES.md`의 `Next 3 Implementation Priorities` 1번을 M122 완료 상태로 갱신하고,
  다음 웹 조사 개선 방향은 advisory를 통해 결정한다고 남겼다.
- `docs/TASK_BACKLOG.md`의 next-phase target 라인에 M122 Axis 3 완료 문구를 추가했다.
- `docs/TASK_BACKLOG.md` 완료 목록에 `143. M122 Axis 3: UNRESOLVED display/hint propagation`
  항목을 추가했다.
